The button now reads "Pay with Klap" (`label="short"`: "Klap") and shows the Klap logo instead of the Klap One symbol. On the `black` variant the logo and label use the Klap brand color (`#d9d4cb`); on `white` both are ink (`#09090b`). No API changes — attributes, events, and types are unchanged, and `--klappay-color` still overrides the label color.
